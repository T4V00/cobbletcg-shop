🚀 How to install

  1. Create a Minecraft 1.21.1 profile with NeoForge 21.1+ (the CurseForge app does it for you).
  2. Add MasterBall Traders API (NeoForge) (⏳ waiting for CurseForge approval) and MasterBall Traders Co. (NeoForge) (plus CobbleDollars if you like) to mods. Cobblemon is strongly recommended.
  3. Open a world: you start with 5 packs and a binder.
  4. Buy a TCG Phone from the Mysterious Wholesaler, a travelling merchant who shows up near players.
  5. Press Y for the mod options (official art download, card art and more).

On a server: install the same mods on the server and on every client.
