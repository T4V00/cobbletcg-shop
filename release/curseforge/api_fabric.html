🎁 What it provides

🃏 Every physical card11,767 cards and 272 sealed packs from 68 sets, from Base Set (1999) to the 2026 sets. No TCG Pocket cards.
✨ Official rarities42 rarities from Common to Mega Hyper Rare, each era's holo pattern and print variants: reverse holo, Poké Ball and Master Ball reverse, 1st Edition, Shadowless and more.
📦 Realistic packs5 cards drawn by official rarity family, rare semi-god packs and god packs that are always full art.
🎨 Original art by defaultEvery card gets generated pixel art with a type-colored border and its real name. No official art is included.
🖼️ Official art, if you want itOn first launch the API asks whether to download the official card art (~3 GB, resumable, with a progress bar). Change your mind any time with Y → Download official art.
📁 Your own imagesDrop images in PNGS POKEMOMN or the imageFolder set in config/masterball-api.json.

🛠️ For mod developers

Version 0.3.0 adds a loader-independent platform layer (dev.masterball.api.platform): networking, events, renderers, player data and more, with a bridge for each loader. MasterBall Traders Co. is built on it, so its code is shared between Fabric and NeoForge.
